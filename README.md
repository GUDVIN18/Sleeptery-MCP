# Sleeptery-MCP

MCP-сервер для подключения AI-ассистентов к сервисам Sleeptery. Предоставляет доступ к ежедневной и недельной статистике сна, записям дневника и целям пользователя.

Проект помогает ассистенту анализировать сон и привычки на основе реальных данных, находить закономерности и формировать персональные рекомендации. Включает готовые инструкции для анализа статистики и дневника сна.

Написан на Python с использованием MCP, HTTPX и Pydantic.

## Запуск в Docker

Создайте файл настроек (если `.env` ещё нет):

```bash
cp .env.example .env
```

В `.env` укажите `DOCKER_SECRET` и адреса сервисов `ST_SLEEP_URL`,
`ST_DIARY_URL`, `ST_ACCOUNT_MANAGER_URL`. `LOG_LEVEL` задаёт уровень логов.
Ключ `QWEN_API_KEY` нужен только для тестового AI-агента.

```bash
docker compose up -d --build  # Собрать и запустить сервер
docker compose logs -f       # Смотреть логи
docker compose down          # Остановить и удалить контейнер
```

MCP доступен по адресу `http://localhost:8800/mcp`.
Логи сохраняются в Docker-томе `mcp_logs` между перезапусками.

`Dockerfile` собирает образ с Python 3.12 и зависимостями из `uv.lock`.
`compose.yaml` задаёт порт, настройки из `.env` и хранение логов.
