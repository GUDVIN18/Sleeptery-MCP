# Sleeptery-MCP

MCP-сервер для подключения AI-ассистентов к сервисам Sleeptery. Предоставляет доступ к ежедневной и недельной статистике сна, записям дневника и целям пользователя.

Проект помогает ассистенту анализировать сон и привычки на основе реальных данных, находить закономерности и формировать персональные рекомендации. Включает готовые инструкции для анализа статистики и дневника сна.

Написан на Python с использованием MCP, HTTPX и Pydantic.
